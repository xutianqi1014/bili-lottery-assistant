# 顺手清理与构建记录（1.5.7）

日期：2026-09-20。1.5.7 为本地中间构建，相关变更后随 v1.6.0 首次发布；包含此前 1.5.6 优先项优化。

## 完成范围

### 1. 整数列表 JSON 解析去重

- 在 `backend/domain/json_utils.py` 增加 `load_json_ints`，由官方执行、非官方执行、运行状态、来源闭合四个模块共同使用。
- 保持非法 JSON、非数组输入返回空列表，保留整数顺序、重复项及原先 bool 属于 int 的行为，不转换字符串或浮点数。
- 调用模块保留 `_load_json_ints` 导入别名。接收已解析对象的两处过滤函数输入契约不同，不强行合并。

### 2. 来源适配器精简

- 糯米背包与抽奖合集适配器删除完全重复的文章读取方法，直接继承父类实现。
- 抽奖合集与番茄薯条共用 `select_latest_named_readlist`，保留标题规范化后的精确匹配、更新时间与字符串 ID 排序、各自错误码及选择结果的兼容索引。
- 番茄薯条自身的文章读取与发布日期排序保持不变；主来源双主页流程保持不变。
- 抽奖合集注释不再写死十篇，实际数量仍由配置决定。

### 3. 移除无引用旧模块

- 删除 `backend/source_adapters/lottery_toolman/config.py` 中的旧配置类。
- 删除 `backend/browser/locator_utils.py` 中未使用的 `stable_class_state`。
- 删除前检查代码、测试与打包入口，未发现调用或动态导入，也未通过包入口导出。两个文件均已在 Git 历史中记录，可恢复；不保留已删除内部模块的外部导入路径。
- 不删除用户数据、旧版可执行包或此前的优化改动。
